`setInterval` は cleanup を忘れると、**コンポーネントがアンマウントされても勝手に動き続ける** 典型的なリーク源です。

操作パネルで **対策: 対策なし** になっていることを確認し、「1 サイクル実行」ボタンを数回押してみてください。

### 観察のポイント

- **Timer カウント** が毎サイクル 10 ずつ積み上がる（1 サイクル = 1 マウント/アンマウントの往復 × `cycleCount`）
- **ヒープ** もゆっくりと右肩上がりになる
- 「対策: cleanup あり」に切り替えてさらに数回押すと、Timer カウントは増えない

### 実務コードで当てはめると

```tsx
useEffect(() => {
  const id = setInterval(() => pollStatus(), 1000)
  // ❌ return 文を書き忘れるとリーク
  return () => clearInterval(id)
}, [])
```

この `return () => clearInterval(id)` が **cleanup**。書かないと unmount 時に Timer が残ります。
