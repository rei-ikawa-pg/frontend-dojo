まずはメモリリークを「作る」前に、**静止状態のヒープ使用量** を把握します。

右側のチャートが「現在のページが使っているヒープ量」です。何もしなければ、多少の揺らぎはあっても
ほぼ横ばいになります。もし画面を触っていないのに右肩上がりになっている場合は、
このページ自体に別のリークが潜んでいるサインです（本 Lab はそうならないように作っています）。

### DevTools と組み合わせる

Chrome DevTools の **Memory** パネルには「ゴミ箱アイコン（Collect garbage）」があり、
これを押すと強制的に GC が走ります。チャートが一瞬下がる様子を観察してみてください。
GC で下がる分は「最初から解放可能だった」メモリです。
リークとは「GC を走らせても下がらないメモリ」のことを指します。
