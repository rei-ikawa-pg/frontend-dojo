DOM から外した要素でも、JS 変数がその参照を握っていれば GC は走りません。
これが **Detached DOM リーク** です。「画面には居ないのにヒープにはいる」という直感に反する状況が生まれます。

### 観察のポイント

- 保持サイズを **中 (100K)** 以上にして「1 サイクル実行」を押す
- **Detached カウント** が増える — これが「消したつもりで握っている要素」の数
- **ヒープ** は Detached カウントと連動して階段状に増加

### なぜ消えない？

```tsx
const ref = useRef<HTMLDivElement | null>(null)
useEffect(() => {
  // コンポーネントが unmount されるとき、DOM からは抜ける
  // でも ref.current は依然としてその要素を指している → GC できない
  return () => {
    ref.current = null // ← これを書かないと握ったまま
  }
}, [])
```

### WeakRef に切り替えると

`WeakRef` は **GC を妨げない参照** です。
対策を WeakRef に切り替えて同じ操作をすると、GC 発生タイミング次第で
Detached カウントがじわじわ減っていく様子が観察できます（DevTools の GC ボタンを併用すると分かりやすい）。
