ブラウザが 1 枚の絵を描き終えるまでには、大まかに次の段階があります。

- <Term id="style">**Style**</Term> — 各要素にどの CSS ルールが当たっているかを確定させる
- <Term id="layout">**Layout**</Term> — 位置とサイズを計算する
- <Term id="paint">**Paint**</Term> — ピクセル列として描く（まだ GPU には送られていない）
- <Term id="composite">**Composite**</Term> — レイヤーを GPU で合成し、最終画面に出す

1 フレームは約 **16.67 ms** 以内に全部終わらせたい領域（<Term id="frame-budget">フレームバジェット</Term>）。
これを超えると <Term id="fps">FPS</Term> が落ち、ユーザーには「カクつき」として見えます。

このステップでは何も動かしません。次から 1 つずつ、
どのプロパティが **どこまでのフェーズを引き起こすか** を手で確かめていきます。
