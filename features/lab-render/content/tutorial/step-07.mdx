要素数を一気に **2000** に増やしました。
プロパティは軽いはずの `transform` だけです。

- 要素数 500 では 60 <Term id="fps">FPS</Term> が余裕だったのに、2000 では落ちるかもしれません
- `Rendering`（<Term id="composite">Composite</Term>）の時間が支配的になります

これが **「要素数で殴れば軽い CSS でも重くなる」** という現実です。
実機で見える「スクロールが少しカクつく」の原因の多くは、
軽い CSS × 多数の要素 の組み合わせから来ています。

<Term id="frame-budget">フレームバジェット</Term>（60 FPS なら 16.67ms）を超え始めると、
FPS は目に見えて落ちます。低スペック端末を想定するなら、この画面が **再現環境** になります。
