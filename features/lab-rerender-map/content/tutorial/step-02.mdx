### memo の正体

```tsx
const MemoChild = React.memo(Child)
```

`React.memo` は **前回と今回の props を浅い比較 (shallow equal)** するだけの、
非常に機械的な仕組みです。

- primitive: 値比較 (`===`)
- object/array/function: 参照比較 (`===`)

だから今回の例のように primitive の props (`value={42}` など) を渡している限り、
memo は完璧に効きます。次のステップで、この前提がどう崩れるかを見ます。
