### memo の正体

```tsx
const MemoChild = React.memo(Child)
```

`React.memo` は **前回と今回の props を浅い比較（shallow equal）** するだけの、
非常に機械的な仕組みです。

- primitive: 値比較（`===`）
- object / array / function: 参照比較（`===`）

今回の例は primitive の props（`value={42}` のような値）を渡しているため、
memo は完璧に効きます。次のステップでは、この前提がどう崩れるかを見ます。
