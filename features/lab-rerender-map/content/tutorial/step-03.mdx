メモ化された子に `{ id: 1 }` のような **object literal** を渡すとどうなるか。操作パネルで prop 種別を `object-literal (毎回新規)` に切り替えてください。

### 観察のポイント

- memo があるにも関わらず、子 A が毎回 flash する
- カウンタが増え続ける

### なぜこうなるか

```tsx
// 親の中でこう書くと…
<MemoChild user={{ id: 1 }} />
// 毎 render で `{ id: 1 }` は「別の新しいオブジェクト」として生成される
// memo の shallow equal は参照比較なので、毎回「違う」と判定される
```

同じことが **関数 (`onClick={() => ...}`)** にも起きます。矢印関数は呼び出されるたびに
新しい関数オブジェクトが生まれるため、memo を貫通します。

### 対策

- 参照を親側で安定させる: `useMemo(() => ({ id }), [id])` / `useCallback`
- そもそも object をまとめず primitive を渡す
- Zustand / Jotai 等の selector で「本当に必要な値だけ」渡す

「memo を付けたのに止まらない」は、ほぼこの object literal か function が原因です。
