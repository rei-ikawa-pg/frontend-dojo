DOM ツリーから切り離されたが、JS からはまだ参照されている要素を **Detached DOM** と呼びます。
参照が残っている限り GC は走らず、「画面には居ないのにヒープにはいる」という直感に反する状況が生まれます。

### 観察のポイント

- 保持サイズを **中 (100K)** 以上にして「1 サイクル実行」を押す
- **Retained** カードのカウントが増える（内訳は保持中の Detached DOM で、「消したつもりで握っている要素」の数）
- **Heap** も Retained の増加と連動して階段状に上がる

### なぜ消えない？

`useRef` の中身は React の管理外で、unmount 時に自動で `null` にはなりません。
参照を切りたい場合は cleanup で自分で代入する必要があります。

```tsx
const ref = useRef<HTMLDivElement | null>(null)
useEffect(() => {
  // コンポーネントが unmount されるとき、DOM からは抜ける
  // でも ref.current は依然としてその要素を指している → GC できない
  return () => {
    ref.current = null // ← これを書かないと握ったまま
  }
}, [])
```

### WeakRef に切り替えると

`WeakRef` は **GC を妨げない参照** です。
値を取り出すときは `ref.deref()` を呼びますが、結果は `undefined`（既に回収済み）の可能性があるため都度チェックが必要です。
対策を WeakRef に切り替えて同じ操作をすると、GC 発生タイミング次第で
Retained カウントがじわじわ減っていく様子が観察できます（DevTools の GC ボタンを併用すると分かりやすい）。
