`setInterval` は cleanup を忘れると、**コンポーネントがアンマウントされても勝手に動き続ける** 典型的なリーク源です。

操作パネルで **対策: 対策なし** になっていることを確認し、「1 サイクル実行」ボタンを数回押してみてください。

### 観察のポイント

- **Timers / Listeners** カード左側の `timers` 値がボタン 1 回押下ごとに `+10` ずつ積み上がる
  （「1 サイクル実行」ボタンはプリセットで設定された `cycleCount`（このステップでは `10`）回のマウント/アンマウント往復を連続で回します）
- **Heap** カードもゆっくりと右肩上がりになる
- 「対策: cleanup あり」に切り替えてさらに数回押すと、`timers` 値は増えない

### 実務コードで当てはめると

```tsx
useEffect(() => {
  const id = setInterval(() => {
    // 何らかの定期処理（ポーリング、アニメーションなど）
  }, 1000)
  // ❌ この return を書き忘れると、unmount 後も setInterval が動き続ける
  return () => clearInterval(id)
}, [])
```

この `return () => clearInterval(id)` が **cleanup**。書かないと unmount 時に Timer が残ります。
