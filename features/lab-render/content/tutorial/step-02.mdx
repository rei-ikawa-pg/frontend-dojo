`width` を毎フレーム変えるとどうなるでしょうか。

width の変更は **「この要素の幅が変わる → 周囲のレイアウトも再計算が必要かもしれない」** という扱いになるため、
<Term id="layout">Layout</Term> から最後まで全部走ります。

右の「Theory vs Actual」テーブルでは:

- **理論** … <Term id="css-triggers">CSS Triggers</Term> が「Layout が必要」と言っている
- **実測** … <Term id="loaf">LoAF</Term> API で `Style+Layout` が実際に時間を食っている

の両方に ○ がつくはずです。
<Term id="fps">FPS</Term> も、要素数が増えるほど下がりやすくなることに注目してください。
