最初は最小構成から始めます。Root → A → B の 3 層 (深さ 1, fanout 1) で、
右側「state を更新」ボタンを押してみてください。

### 何が起きているか

- Root の `useState` が変化 → Root 自身が再 render
- その JSX に現れる子 A も再 render (memo なし)
- A の JSX に現れる B も再 render

木全体が一斉に flash するはずです。カウンタを見ると、クリック回数に比例して total renders が増えます。

### 「伝播」という言葉の正体

React の再 render の「伝播」は、props を介した呼び出しグラフの辿り直しです。
ブラウザの describe 層で特別なイベントを配っているわけではなく、
**親の JSX を実行すると子の関数が呼ばれる、という JS レベルのごく自然な挙動** に過ぎません。

ここを掴めると、後のステップで出てくる「memo で止まる / object prop で効かない」も、
同じ JS の枠組みで説明できるようになります。
