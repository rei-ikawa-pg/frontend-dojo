次は `background-color` を変えてみます。

色はピクセルの値なので <Term id="paint">**Paint**</Term>（塗り直し / <Term id="repaint">Repaint</Term>）は必要ですが、
位置やサイズには関係しないので **Layout は走りません**。

確認ポイント:

- `Style+Layout` の時間が ≒ 0 ms に張り付く
- `Rendering`（<Term id="paint">Paint</Term> + <Term id="composite">Composite</Term> の合算）にだけ時間が乗る
- FPS は width の時より明らかに余裕がある

これが「重い CSS / 軽い CSS」の差の第一歩です。
色は軽く、**サイズ・位置は重い**。
